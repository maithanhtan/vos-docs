Gửi `sessionToken` hiện có qua header `X-Auth-Session-Token`, không gửi nội dung yêu cầu. Dùng token phiên tài khoản nhận được sau khi xác thực.

## Tiếp tục phiên

Chạy ví dụ Bash với `curl` và `jq`.

```bash
AUTH_BASE_URL="https://platform.verolabs.co"
COOKIE_JAR="$(mktemp)"
chmod 600 "$COOKIE_JAR"
read -r -s -p "Token phiên: " SESSION_TOKEN
printf '\n'

AUTH_RESPONSE="$(curl --silent --show-error --fail-with-body \
  --request POST "$AUTH_BASE_URL/api/auth/mfa/resume" \
  --cookie-jar "$COOKIE_JAR" \
  --header "X-Auth-Session-Token: $SESSION_TOKEN")"
unset SESSION_TOKEN

printf '%s\n' "$AUTH_RESPONSE" | jq '{status, methods, expiresAt}'
```

## Xử lý phản hồi

Phản hồi tuân theo [luồng đăng nhập](/vi/apis/rest/auth/post-api-auth-login#luồng-đăng-nhập):

- `authenticated`: dùng `jwt` để gọi REST API.
- `mfa_required`: giữ cookie jar và [xác minh yếu tố thứ hai](/vi/apis/rest/auth/post-api-auth-mfa-verify) bằng phương thức có trong `methods`. API chưa cấp JWT.

Tiếp tục bước 2 hoặc 3 trong [quy trình đăng nhập](/vi/apis/rest/auth/post-api-auth-login), tùy trạng thái phản hồi. Dùng cùng phiên lệnh và cookie jar. Xoá cookie jar khi hoàn tất xác thực.

Thiếu token trả HTTP `401` với `session_missing`. Đăng nhập lại nếu phiên không còn hợp lệ. Yêu cầu từ trình duyệt phải có origin là `https://platform.verolabs.co`.
