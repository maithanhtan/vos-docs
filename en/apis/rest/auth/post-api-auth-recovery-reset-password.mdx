---
title: 'Set a new password'
description: 'Update your password after completing the required recovery checks'
openapi: '/openapi.oms.en.json POST /api/auth/recovery/reset-password'
---

Send the new password in `password`, together with the latest recovery cookie. Complete [email-code verification](/en/apis/rest/auth/post-api-auth-recovery-verify) and any required [second-factor verification](/en/apis/rest/auth/post-api-auth-mfa-verify) first.

## Response states

HTTP `200` confirms the password update. Check `status` before accessing the REST API:

| `status` | Next action |
| --- | --- |
| `authenticated` | Use `jwt` as `Authorization: Bearer <jwt>` for REST API requests. |
| `mfa_required` | Preserve the challenge cookie and [verify a second factor](/en/apis/rest/auth/post-api-auth-mfa-verify) before using the REST API. |

The response clears the recovery cookie. Preserve any challenge cookie until verification is complete. Keep the new password and issued tokens confidential.
