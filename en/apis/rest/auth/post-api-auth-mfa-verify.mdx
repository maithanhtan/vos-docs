---
title: 'Verify two-factor authentication'
description: 'Complete a pending second-factor challenge with an authenticator or backup code'
openapi: '/openapi.oms.en.json POST /api/auth/mfa/verify'
---

Call this endpoint when [login](/en/apis/rest/auth/post-api-auth-login), [session resumption](/en/apis/rest/auth/post-api-auth-mfa-resume), or [password recovery](/en/apis/rest/auth/post-api-auth-recovery-verify) returns `status: "mfa_required"`.

## Verification requirements

Send the `vos_mfa_challenge` cookie from the preceding response. Use a cookie jar for command-line or server requests. Browser requests must use the `https://platform.verolabs.co` origin. The cookie is HttpOnly; do not read or modify its value.

Send only `method` and `code` in the body. Additional fields are rejected. No Bearer JWT is required.

| `method` | `code` | Condition |
| --- | --- | --- |
| `totp` | Current authenticator code as a six-digit string, including leading zeros. | `totp` appears in `methods`. |
| `lookup_secret` | An unused saved backup code as a string. | `lookup_secret` appears in `methods`. Each code can be used once. |

The [login procedure](/en/apis/rest/auth/post-api-auth-login#2-verify-the-second-factor-when-required) contains a cURL example with cookie handling.

## Successful verification

HTTP `200` returns `status: "authenticated"`, `jwt`, `sessionToken`, and session details. Both `session` and `tokenizedSession` report `authenticator_assurance_level: "aal2"`. The response clears the challenge cookie. Use `jwt` for REST API requests.

During password recovery, preserve all updated cookies and [set the new password](/en/apis/rest/auth/post-api-auth-recovery-reset-password) after verification.

## Error handling

| HTTP status | Error code | Next action |
| --- | --- | --- |
| `400` | `invalid_code` | Correct the method or code format. |
| `400` | `invalid_mfa_request` | Check the code and retry while the challenge is valid. |
| `401` | `session_invalid` | Log in again. |
| `403` | `origin_not_allowed` | Use the authentication origin for browser requests. |
| `403` | `session_invalid`, `session_refresh_required`, `session_aal2_required` | Restart authentication and complete the required steps. |
| `410` | `challenge_expired`, `flow_expired` | Restart login or session resumption to obtain a new cookie. |
| `429` | `rate_limited` | Wait before retrying. |
| `502` | `mfa_incomplete`, `mfa_service_unavailable` | Authentication did not complete. Retry later. |
